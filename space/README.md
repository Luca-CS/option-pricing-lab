# Option pricing lab

Interactive demo of [Luca-CS/option-pricing-lab](https://github.com/Luca-CS/option-pricing-lab):
European, American (Longstaff-Schwartz), Asian and barrier options under Black-Scholes, Heston,
Dupire local volatility and a Heston stochastic-local-volatility model calibrated by the particle
method, on an SPX option snapshot.

Only calibrated parameters ship with the Space; the market quotes are not redistributed.
